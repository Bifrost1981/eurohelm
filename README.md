# EuroHelm – Prototyp

**Nicht zur Navigation.** Offline-fähige Seekarten-App (PWA) aus offenen Daten. Die Tiefen, Seezeichen und
Gefahren können fehlen oder falsch sein; amtliche Seekarten und Seehandbücher bleiben maßgeblich.

Öffnen: die Seite im Browser aufrufen, am iPhone „Teilen → Zum Home-Bildschirm“, danach unter
Boot → Offline-Detailkarten die gewünschten Kacheln speichern.

## Daten und Lizenzen

- Tiefen: EMODnet Bathymetry Consortium, EMODnet Digital Bathymetry (DTM), CC BY 4.0
- Küste, Seezeichen, Gefahren, Häfen, Schutzgebiete: © OpenStreetMap-Mitwirkende, Open Database License (ODbL 1.0),
  Seezeichen nach dem OpenSeaMap-Schema. Die Kartenpakete unter `packs/` sind aus OpenStreetMap abgeleitete
  Datenbanken und stehen ebenfalls unter der ODbL 1.0 (https://opendatacommons.org/licenses/odbl/1-0/).
- Land der Übersichtskarten: Natural Earth (gemeinfrei)

Inhalt: App und 46 Detailkacheln, zusammen 167 MB.
